# Sergio7 的博客

这是一个基于 [Hugo](https://gohugo.io/) 构建的个人博客，旨在记录生活、技术探索与思考。这里不仅是我的技术笔记，也是我的“第二大脑”。

## 核心内容

- **数字生活 (Digital Life)**：基于Obsidian的知识管理系统，通过自动化脚本与工具流（Workflow）实现知识的沉淀与博客发布。
- **技术折腾**：涵盖 Linux 环境配置、服务器管理、开源自托管服务等技术实践。
- **日记与记录**：记录每日的反思、工作进度与生活随笔。
- **书籍与阅读**：沉淀读书笔记，构建个人知识资产。
- **主题开发**：基于 [hugo-theme-stack](https://github.com/CaiJimmy/hugo-theme-stack) 进行定制，持续优化阅读体验。

## 项目结构

- `content/`：博客文章与页面内容。
    - `posts/`：技术文章与深度思考，记录技术折腾的过程。
    - `diary/`：日常记录与生活点滴。
    - `books/`：书籍阅读笔记与知识沉淀。
    - `about/`：个人介绍页面。
    - `page/`：站点辅助页面（如归档、搜索）。
- `assets/`：静态资源（图片、图标、自定义样式）。
- `scripts/`：用于自动化构建与部署的辅助脚本。
- `hugo.yaml`：站点配置文件。
