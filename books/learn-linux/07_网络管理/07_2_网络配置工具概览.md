# 7.2 网络配置工具概览

在 Linux 系统中配置网络有多种方式，主要分为两类：

- **临时配置**：命令立即生效，但重启网络服务或系统后失效，适用于测试或临时调整。
- **持久化配置**：通过配置文件定义，系统重启后自动生效，用于生产环境。

Ubuntu 系统常用的网络工具有：

| 工具                | 类型         | 说明                                                                                     |
|---------------------|--------------|------------------------------------------------------------------------------------------|
| `ifconfig`          | 临时配置     | 传统命令，用于查看和设置网络接口参数（IP、MAC、MTU 等）。属于 `net-tools` 包，已停止维护，功能被 `ip` 替代。 |
| `ip`                | 临时配置     | 现代命令，来自 `iproute2` 包，功能更强大，整合了 `ifconfig`、`route`、`arp` 等工具的功能。推荐使用。 |
| `netplan`           | 持久化配置   | Ubuntu 17.10 起默认的抽象网络配置工具，通过 YAML 文件定义接口配置，可生成 `systemd-networkd` 或 `NetworkManager` 的底层配置。 |
| `systemd-networkd`  | 持久化配置   | systemd 的网络管理服务，通过 `.network` 文件配置，适用于服务器环境。`netplan` 可以生成其配置。 |
| `NetworkManager`    | 持久化配置   | 动态网络管理服务，常用于桌面环境，支持 GUI 和命令行管理（`nmcli`）。`netplan` 也支持将其作为渲染器。 |

## 学习路径建议

1. **先掌握临时配置工具**：学会使用 `ifconfig` 或 `ip` 查看网络状态、临时修改 IP 等操作。`ip` 是未来趋势，建议优先学习。
2. **再学习持久化配置**：理解 `netplan` 的工作原理和 YAML 语法，能够编写配置文件并应用生效。
3. **深入底层**：了解 `systemd-networkd` 或 `NetworkManager` 的配置文件，以便在无 `netplan` 的环境下工作。

后续章节将详细介绍 `ifconfig`（传统工具）和 `netplan`（Ubuntu 默认配置工具），并穿插 `ip` 命令的现代用法。
